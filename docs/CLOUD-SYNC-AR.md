# مزامنة المحتوى (داخلي)

## ماذا يحدث؟

- بيانات المحتوى تبقى محفوظة محليًا كما هي (لا تُمسح).
- زر **رفع الكل إلى السحابة** في `/admin` يرفع:
  - المهن
  - المقالات
  - التصنيفات
  - المدن
  - الأصول الرقمية
  - معرض الصور
  - إعدادات الموقع
- الرفع يحدّث حسب المعرّف — **لا يحذف** سجلات أخرى موجودة مسبقًا.
- الموقع يقرأ من السحابة عند التوفر، مع دمج آمن مع النسخة المحلية.

## إعداد الدخول

1. فعّل قاعدة البيانات السحابية للمحتوى في لوحة المشروع التقنية.
2. فعّل تسجيل الدخول بالبريد وكلمة المرور.
3. أنشئ مستخدم أدمن (Email + Password).
4. `/admin/login` يطلب البريد + كلمة المرور فقط.
5. انشر قواعد الكتابة: قراءة عامة، كتابة بعد تسجيل دخول فقط.

### أول رفع

ادخل لوحة التحكم — أول زيارة ترفع البيانات تلقائيًا إن كانت السحابة فاضية، أو استخدم زر الرفع يدويًا.

## متغيرات البيئة

انظر `.env.example` (محلي، لا يُرفع على Git).

## بعد الربط

1. شغّل الموقع.
2. ادخل `/admin/login`.
3. ارفع المحتوى إن لزم.
4. راجع السجلات في لوحة المشروع التقنية.
