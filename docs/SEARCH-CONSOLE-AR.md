# Search Console — بعد اعتماد النشر

لا تُعتبر قابلية الزحف إثباتًا للفهرسة.

1. ثبّت الدومين الأساسي `https://www.saedniksa.com` (HTTPS + تحويلات بدون حلقات).
2. أضف الخاصية في Google Search Console (تفضيل Domain أو URL-prefix على www).
3. أكمل التحقق من الملكية (DNS TXT أو ملف HTML — حسب اختيارك).
4. أرسل الخريطة: `https://www.saedniksa.com/sitemap.xml`
5. راقب التغطية: استبعاد المسودات، 404، صفحات `noindex` مثل `/sa/` غير المكتملة.
6. اختبر عناوين/أوصاف من نتائج الفحص الحي بعد النشر، لا من الافتراض.

`robots.txt` يشير للخريطة ولا يُستخدم كبديل لحماية المسودات (المسودات محمية بقواعد السحابة + عدم العرض العام).
