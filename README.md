# ساعدني — Saedni

Frontend prototype for a Saudi local trades content platform covering cities across the Kingdom.

## Stack

- React + TypeScript
- Tailwind CSS
- React Router
- Tajawal + IBM Plex Sans Arabic (RTL-first)

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Notes

- Arabic-first knowledge site for trades and services in Saudi Arabia.
- Public site is content-only in the current phase.
